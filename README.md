# CalorieTracker

**Prosta i intuicyjna aplikacja do liczenia kalorii oraz makroskładników.**

## O projekcie

CalorieTracker to aplikacja tworzona przez czteroosobowy zespół studentów informatyki w ramach zajęć **„Projekt zespołowy systemu informatycznego”**.

Naszym celem jest stworzenie prostego narzędzia do codziennego monitorowania diety, które będzie wygodną alternatywą dla rozbudowanych aplikacji dietetycznych, kalkulatora i tradycyjnego notatnika.

Stawiamy na **prostotę i wygodę użytkowania**. Aplikacja pozwoli szybko przeliczać wartości odżywcze produktów na dowolną porcję, zapisywać spożyte posiłki oraz kontrolować własne cele żywieniowe — bez zbędnych funkcji i skomplikowanej obsługi.

## Technologie

- **Python + Streamlit** – logika i interfejs aplikacji.
- **SQLite** – lokalna baza danych.
- **GitHub** – zarządzanie projektem i współpraca zespołowa.
